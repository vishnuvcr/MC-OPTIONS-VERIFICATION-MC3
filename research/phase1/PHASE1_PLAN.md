# Phase 1 — Authority Recovery and Exact Method Definition

## Objective

Determine exactly how the original BATMAN Monte Carlo generates the future path distribution and what evidence supports that definition.

## Evidence hierarchy

1. Original source code or notebook.
2. Original technical documentation or publication.
3. Attributable original demonstration/video with identifiable outputs.
4. Reproducible original output artifacts.
5. Earliest project implementation lineage.
6. Generic literature for candidate-method interpretation only.

## Required tasks

- Trace MC1 to its earliest MC and trade-engine commits.
- Define the 756-observation boundary exactly.
- Determine the D3 09:30 starting-spot rule.
- Determine future-return sampling and dependence.
- Determine horizon and compounding transformation.
- Determine quantile extraction and strike mapping.
- Search for independent original BATMAN evidence.
- Record unresolved provenance separately from implementation certainty.

## Stopping rule

Phase 1 stops after the planned evidence searches and predecessor-lineage audit. It does not expand into open-ended internet research.

## Deliverables

- observation definition;
- method authority matrix;
- literature review;
- Phase 1 results;
- deterministic reconstruction utilities and tests;
- manual workflow specification;
- status and error records.
